# 테슬라 요금 및 가격 카드 노출 정책

- 노출 기준: 휴게소 내 테슬라 수퍼차저는 **매직독 설치 여부와 관계없이** 노출·요금 비교 대상에 포함합니다. 매직독 설치 여부는 호환 안내의 표시 기준으로만 사용합니다. 기존 경로·100kW 이상 설비·운영 상태 기준은 유지합니다.
- 앱 노출명: **수퍼차저**. 테슬라는 운영기관 식별값으로 관리하며 요금 전용 태그의 “테슬라 전용” 문구는 유지합니다.
- 매직독 설치가 확인된 수퍼차저를 선택하면 `selected-box-detail-info-CSS`(129×119px)를 사용하고 하단에 **(CSS 호환 가능)**을 표시합니다. 미설치 또는 미확인인 경우 기존 상세 박스(129×97px)를 사용하며 해당 문구는 표시하지 않습니다. 호환 문구는 제공된 Figma 문구 기준입니다.
- 사용자 확정 요금: 대상 테슬라 운영기관에 339원/kWh 적용(테슬라 차주 전용, 2026-11-02 지정). 매직독 이용 가능 여부와 해당 요금의 이용 대상은 별도 기준임.
- 동일 휴게소 내 운영기관 선정 및 경로 최저가·추천 계산에 포함. 기존 100kW 이상 설비·운영 상태·점수·동점 처리 기준 유지.
- 테슬라가 경로의 **최저가로 추천 선정(단독·공동 포함)**되면 가격 카드에 `최저가`와 `테슬라 전용` 표시. `추천` 태그는 표시하지 않음.
- 최저가 추천 테슬라는 분홍색(#EC3F78), 일반 테슬라는 파란색(#2477DB) 전용 태그·요금 적용. Figma `box-detail-info-recommended-tesla` / `box-detail-info-default-tesla` 배치 적용: 기존 340×81px 박스 유지, 왼쪽 충전기 아이콘·태그·요금, 오른쪽 방향·휴게소명 중앙 배치. 태그 38×18px + 58×18px, 간격 2px.
- 공동 최저가 중 추천으로 선정된 테슬라는 분홍색 `테슬라 전용 + 최저가` 유지. 추천되지 않은 초록색 `공동 최저가` 카드에만 전용 태그·색상·배치를 적용하지 않고 기존 공통 디자인 유지.
- 일반 테슬라 충전소는 `테슬라 전용` 태그를 표시하며 기본 파란색 충전기 아이콘·요금을 사용. 추천 핀·최초 포커스 선정 기준은 변경하지 않음.
- 엑셀 재수입 시 `scripts/apply-tesla-fares.cjs`가 요금을 적용하고 운영기관·경로 추천을 재계산함.

- 제외: 신탄진(서울, 테슬라 없음), 행담도(휴게소와 떨어져 있음).
- 참고용: 고양(판교·문산)은 매직독이 있으나 경로 데이터가 없어 노출하지 않음.
- 2026-11-02 반영 결과: 9곳(휴게소·방향 기준), 경로별 중복 포함 133행. 매직독 확인 8곳, 미설치 1곳. 테슬라 단독 최저가 43개 경로, 공동 최저가 추천 3개 경로.
