# 테슬라 요금 및 가격 카드 노출 정책

- 사용자 확정 요금: 모든 테슬라 운영기관에 339원/kWh 적용(테슬라 차주 전용, 2026-11-02 지정).
- 동일 휴게소 내 운영기관 선정 및 경로 최저가·추천 계산에 포함. 기존 100kW 이상 설비·운영 상태·점수·동점 처리 기준 유지.
- 테슬라가 경로의 **단독 최저가로 추천 선정**되면 가격 카드에 `최저가`와 `테슬라 전용` 표시. `추천` 태그는 표시하지 않음.
- 위 경우에만 Figma `box-detail-info-tesla` 배치 적용: 기존 340×81px 박스 유지, 왼쪽 충전기 아이콘·태그·요금, 오른쪽 방향·휴게소명 중앙 배치. 태그 38×18px + 58×18px, 간격 2px.
- 테슬라가 공동 최저가이면 타사와 동일한 공통 정책 적용: 점수로 선정된 곳은 `최저가 + 추천`, 나머지 공동 최저가는 `공동 최저가`. 테슬라 전용 태그·전용 배치 미적용.
- 일반 테슬라 충전소 노출도 공통 정책 적용. 추천 핀·최초 포커스 선정 기준은 변경하지 않음.
- 엑셀 재수입 시 `scripts/apply-tesla-fares.cjs`가 요금을 적용하고 운영기관·경로 추천을 재계산함.
