# 지도 핀 좌표 기준

- 출처: [Figma 2365:1004](https://www.figma.com/design/2VL2VjPC4MJkNxvIDuPCjM/MJ?node-id=2365-1004)
- 지도 프레임: 329 × 430. 왼쪽 위가 (0, 0). 사이트 기본 화면에서는 (23, 285)에 위치한다.
- 지역명은 그룹 내부 텍스트로 식별하며, 27개 모두 중복·누락 없이 확인했다.
- 핀 좌상단은 Figma에서 추출한 값이다. 좌표 연결점은 깃대 받침 중심으로, 공통 아이콘 내부 오프셋 (4.845, 32.5)을 사용한다. 이는 위경도가 아닌 디자인 좌표다.
- 비율 좌표 X = (핀 왼쪽 + 4.845) / 329, Y = (핀 위 + 32.5) / 430. 지도 크기 변경 시 이 비율로 계산한다. 이미지 크롭이 변경되면 다시 추출한다.
- 출발·도착은 같은 지역 좌표를 사용하며 아이콘 색상으로 구분한다. 겹침 회피를 위해 지역 좌표 자체를 이동하지 않는다.
- 현재 데이터에 같은 이름으로 존재하는 도시에 우선 적용한다. 경기·강원·충북·충남·경북·경남·전북·전남·세종·통영은 이 Figma에 없으므로 기존 좌표를 유지한다. 새 도시의 경로 데이터는 별도로 준비해야 하며 좌표 추가만으로 경로를 생성하지 않는다.
- 실행 데이터: `map-city-pins.js`에는 현재 목록과 일치하는 14개만 포함한다. 지도 깃발 옆에는 실제 선택한 지역명을 표시한다. 기본 간격은 4px이며, 좌우·상하 후보 중 다른 UI와의 겹침이 적은 위치를 선택한다.
- 전체 27개는 별도 보관용 파일 [좌표 리스트](map-pin-coordinates-27.md)와 `map-pin-coordinates-27.json`에 저장하며 사이트에서 불러오지 않는다.

## 현재 사이트와 대조한 적용 범위

- 적용 14개: 서울 / 인천 / 강릉 / 속초 / 대전 / 청주 / 제천 / 대구 / 안동 / 포항 / 부산 / 울산 / 창원 / 광주
- 좌표만 저장한 13개: 수원 / 평택 / 여주 / 하남 / 춘천 / 원주 / 천안 / 충주 / 당진 / 경주 / 전주 / 여수 / 목포
- 기존 위치 유지 10개: 경기 / 강원 / 충북 / 충남 / 경북 / 경남 / 전북 / 전남 / 세종 / 통영
- 출발지·도착지 선택 목록은 기존 데이터를 유지한다. 지도 경로선의 시작점과 끝점도 적용된 깃대 받침 좌표에 연결한다.
