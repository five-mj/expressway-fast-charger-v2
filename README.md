## 반응형 화면 정책 (2026-09-28)

기준값은 제품 해상도나 기종명이 아닌 브라우저 viewport의 CSS px입니다.
첫 화면의 기준 크기는 375×812, 메인 화면은 375×892입니다.

| 조건 | 동작 |
| --- | --- |
| 모바일 대상이며 너비 < 480px 또는 너비/높이 < 0.6 | 가로를 꽉 채우고 필요한 만큼 세로 스크롤 |
| 모바일 대상이며 너비 ≥ 480px이고 너비/높이 ≥ 0.6 | 각 화면 전체가 높이에 들어오도록 비율 유지, 가로 중앙 정렬, 좌우 배경 허용 |
| 일반 PC의 너비 ≥ 768px | 기존 375px 중앙 배치와 데스크톱 여백 유지 |

- 모바일 대상: 너비가 768px 미만이거나, 주 입력이 `pointer: coarse`이고 `hover: none`인 터치 화면. 펼친 폴드/태블릿이 768px 이상이어도 대응합니다. 기종명을 판별하지 않습니다.
- 높이는 브라우저 UI를 제외한 `window.innerHeight`, 확대에 쓰는 너비는 스크롤바를 제외한 `document.documentElement.clientWidth`입니다. 모드 전환은 스크롤바에 의한 반복 전환을 막기 위해 `innerWidth`를 사용합니다.
- 높이 맞춤 배율 = `min(사용 가능 너비 / 375, max(0.85, 화면 높이 / 디자인 높이))`.
- 가로모드처럼 높이가 부족하면 최소 배율 0.85에서 멈추고 세로 스크롤을 허용합니다. 이는 가독성을 위한 초기 조정값이며 사용자 확대 기능은 제한하지 않습니다.
- 일반 모바일의 가로 채움 모드에서는 기존 동작을 유지합니다. 메인 화면 하단은 그라데이션에서 #0099FF 단색으로 이어집니다.
- 접기/펼치기, 회전, 창 크기 변경 시 재계산합니다. 두 화면의 배율과 문서 높이는 각각 계산하므로 화면 전환 후 빈 스크롤 영역이 남지 않도록 합니다.
- 입력 장치 조건은 기기 종류를 완벽하게 식별하지 않습니다. 터치 노트북이나 연결한 마우스에 따라 분류가 달라질 수 있습니다.

초기 확인 예: 390×844 → 가로 채움, 600×900 → 높이 맞춤,
600×1200 → 가로 채움, 터치 화면 840×900 → 높이 맞춤,
일반 PC 1280×900 → 기존 PC 배치. 실제 폴드 사용성에 따라 480px/0.6/0.85를 조정할 수 있습니다.

구현 위치: `mobile-layout.js`, `styles.preview-5281.css`의 마지막 반응형 규칙.

## 추천 충전소 선정 정책 (2026-09-28 확정)

이 절은 추천 수정본 엑셀과 V2 데이터 변환에 적용하는 정책입니다. 추천 열을 검증한 뒤 해당 결과를 사이트의 최초 선택과 추천 핀에 반영합니다.

1. 출발·도착 조합별로 `경로별_휴게소(순서)`의 순번을 오름차순으로 사용합니다.
2. 운영 중과 오픈예정 충전소를 모두 후보에 포함합니다. 개통상태는 유지하며, 오픈예정인 선택 충전소에는 오픈예정 라벨을 표시합니다.
3. 가격이 최우선입니다. 경로 전체 운영기관 후보의 회원가를 비교해 최저가 그룹을 먼저 구합니다. 유일한 최저가이면 점수와 관계없이 추천합니다.
4. 공동 최저가일 때만 아래 점수를 합산해 추천 1곳을 선정합니다. 더 비싼 충전소는 점수가 높아도 추천 후보가 아닙니다.

| 평가 항목 | 점수 |
| --- | --- |
| 전체 경로의 가운데 순번 | 2점 |
| 가운데 순번의 바로 앞·뒤 | 1점 |
| 나머지 순번 | 0점 |
| 충전기 수 8기 이상 / 4~7기 / 3기 / 1~2기 | 3 / 2 / 1 / 0점 |
| 최대 출력 350kW 이상 / 200kW 이상 / 100kW 이상 / 100kW 미만 | 3 / 2 / 1 / 0점 |

- 위치는 실제 주행거리 대신 **전체 휴게소 목록의 순번**으로 평가합니다. 공동 최저가 후보만 모아서 가운데를 다시 계산하지 않습니다.
- 홀수 개면 가운데 1곳, 짝수 개면 가운데 2곳 모두 2점입니다. 가운데에 바로 인접한 나머지 휴게소만 1점입니다.
- 예: 5곳은 `0,1,2,1,0`, 6곳은 `0,1,2,2,1,0`, 1곳은 `2`, 2곳은 `2,2`입니다.
- 수량·출력은 가격을 비교하는 해당 운영기관 행의 `급속(100kW+) 수`와 `최대 출력(kW)`를 사용합니다. 다른 운영기관 수량을 합쳐 특정 운영기관의 점수로 사용하지 않습니다.
- 총점이 같으면 최대 출력이 높은 곳 → 충전기 수가 많은 곳 → 경로상 순번이 앞선 곳 순서로 결정합니다.
- 추천은 경로당 1곳입니다. 추천 핀에는 `icon_pin_recommended.png`, 나머지 공동 최저가에는 `icon_pin_lowPrice.png`를 사용합니다. 화면 진입 시 추천 핀을 선택하고 선택 핀을 지도 레이어 최상단에 표시합니다.
- 누락된 가격·출력·수량이나 연결 불일치는 임의로 0으로 바꾸지 않고 검토 대상으로 남깁니다.

### 엑셀 수정 범위

- 원본을 보존하고 별도 수정본을 만듭니다.
- 변경 대상은 `경로별_휴게소(순서)` 시트의 `추천` 열(Y/N)뿐입니다. 다른 값, 서식, 시트와 순서는 유지합니다.
- `경로별_요약`의 추천 휴게소는 요청에 따라 수정하지 않으므로 수정된 추천 열과 다를 수 있습니다. 새 추천을 적용할 때는 수정본의 추천 열을 기준으로 합니다.
- 검증 예: 강원→강릉은 춘천 워터 294원이 유일한 최저가이므로 춘천 Y, 홍천·내린천 N입니다. 춘천이 오픈예정이어도 동일합니다.

## 2026-09-17 엑셀 데이터 반영

- 원본: `20260917_개발팀전달_경로별_휴게소_통합_추천수정.xlsx`. 파일 SHA-256은 생성 데이터의 `sourceSha256`에 기록합니다. 엑셀 원본은 저장소에 게시하지 않습니다.
- 배포 데이터: `data.generated-20260917.js`. 300개 출발·도착 조합 중 휴게소 목록이 있는 287개 경로, 1,584개 순번 행을 표시합니다. 휴게소가 없는 13개 조합은 기존 입력 정책에 따라 선택 목록에서 제외합니다.
- `출발 + 도착 + 순번 + 휴게소 + 방향`으로 운영기관 정보를 연결합니다. 같은 이름의 반대 방향이나 다른 경로 데이터를 대신 사용하지 않습니다.
- 휴게소의 표시 운영기관은 회원가 우선, 동가이면 수량·출력 점수 → 최대 출력 → 충전기 수 기준으로 선정합니다. 추천 휴게소는 수정본의 추천 Y와 전체 경로 계산 결과가 일치해야 변환에 성공합니다.
- 가격이 없는 운영기관은 최저가 비교에서 제외합니다. 상세정보가 없는 휴게소는 순번을 유지하고 `--` / `정보 없음`으로 표시합니다. 가격 누락을 0원으로 바꾸지 않습니다.
- 검정 라벨은 해당 휴게소의 방향입니다. 파란 `오픈예정` 라벨은 현재 표시 운영기관의 개통상태가 오픈예정일 때만 표시합니다. 방향이 비어 있으면 `방향 미상`으로 표시합니다.
- 요금·수량·출력은 엑셀 스냅샷이며 실시간 정보가 아닙니다. 기존 워터 보정 데이터로 덮어쓰지 않습니다. 지도는 기존 도식형 배치를 유지하며 실제 도로 경로를 그린 지도가 아닙니다.
- 최초 반영 확인값(9월 28일): 워터 추천 129개 경로, 이 중 294원 워터 추천 107개 경로. 아래 요금 보완으로 추천 결과가 갱신되었습니다.
- 재생성: Python과 openpyxl 환경에서 `python scripts/import_routes.py <엑셀경로>`. 검증: `node scripts/verify_routes.cjs`.
